# CampusSave — Repair report

## Changes made

### Flutter / Dart
- Rebuilt `lib/services/api_service.dart`. The uploaded copy contained terminal output embedded in the middle of the Dart source, which broke the method declaration and caused cascading analyzer errors.
- Added optional `http.Client` and ID-token provider injection to `ApiService`, so HTTP behavior can be tested without a live Firebase session.
- Added injectable `ApiService` constructors to `OfferRepository`, `OrderRepository`, and `PaymentRepository`.
- Added the missing `AppColors.blue` theme color used by the student impact screen.
- Replaced obsolete demo/fake-repository tests with tests for the current API-backed repositories and API service.
- Removed the unused `state_views.dart` import and unused local variable from the payment screen.
- Added external-browser launching for Konnect payment URLs using the already-declared `url_launcher` dependency.
- Made the API base URL select a sensible default by platform: Android emulator uses `10.0.2.2`; web and desktop use `localhost`. `API_BASE_URL` can still override it.

### Backend
- Checked JavaScript syntax for all backend source files.
- Checked `package.json` and `package-lock.json` as valid JSON.
- Checked frontend API path strings against backend route declarations; the routes referenced by the Flutter source are present.

## Next verification steps (PowerShell)

From the `CampusSave_Fixed` folder:

```powershell
flutter pub get
dart format .
flutter analyze
flutter test
```

If those pass and you have Android platform files configured:

```powershell
flutter build apk --debug
```

For a physical Android phone, set your computer's LAN address:

```powershell
flutter run --dart-define=API_BASE_URL=http://YOUR_PC_LAN_IP:4000
```

The backend also requires a valid Firebase Admin service account. Keep `serviceAccountKey.json` and all `.env` secrets out of shared archives. Configure `GOOGLE_APPLICATION_CREDENTIALS` locally in `backend/.env` before starting the backend.
